# ورقة ولعبة

حوّل ورقة العمل إلى لعبة للسبورة في دقيقة.

1. ألصق الأسئلة، أو حوّل صورة الورقة بأي مساعد ذكاء اصطناعي عبر «انسخ طلب التحويل».
2. راجع الأسئلة.
3. اختر لعبة: سباق الفريقين، توصيل، تصنيف، رتّب الخطوات، افتح الخزنة.

يعمل على الجوال والسبورة، ويمكن تثبيته على الشاشة الرئيسية، والألعاب تعمل دون إنترنت بعد أول فتح.

عند أي تحديث: ارفع رقم `VERSION` في `sw.js` ورقم `?v=` في `index.html` إلى الرقم نفسه.
